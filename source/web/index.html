USPF
Unreal shader proxy fix

          

          

            

            
Removes shader-compilation stutter in DirectX 12 Unreal Engine games. A d3d12.dll layer compiles new pipelines in the background and skips the draws that need them until they're ready, instead of freezing the game.

Notes

          
    
            
  • Single-player and offline use only. A replaced d3d12.dll can be flagged by anti-cheat; USPF refuses games that ship one unless you confirm.
    • 
            
  • Nothing is installed system-wide. USPF writes d3d12.dll and d3d12async.ini next to the game's executable, and an optional marked block in the game's Engine.ini.
    • 
            
  • Run logs are copied to %LOCALAPPDATA%\USPF\runs so their history survives the game folder keeping only the latest run.
